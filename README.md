# Machine Learning Classifiers for Material Properties

A modular Python framework (Classifier, Preprocessor and Evaluator classes)
that predicts material properties with Random Forest classifiers.

Year 2 group project (team of 5), Imperial College London.
Grade: 91.6%, winner of the Year 2 Machine Learning Prize.

## What it does
- Preprocesses the dataset and trains Random Forest classifiers
- Compares classifiers using confusion matrices and learning curves
- Finds the minimum dataset size needed to reach 70% accuracy

## How to run
    pip install [libraries from the import lines at the top of main.py]
    python main.py
